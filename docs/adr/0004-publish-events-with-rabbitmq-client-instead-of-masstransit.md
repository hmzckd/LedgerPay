# Publish events with RabbitMQ.Client instead of MassTransit

LedgerPay talks to RabbitMQ through the official RabbitMQ.Client library, with a small publisher and an outbox relay of our own, and not through MassTransit. MassTransit 9 needs a paid license with no free tier, and MassTransit 8 is no longer supported, so neither is a good base for a service that should keep getting security fixes. RabbitMQ.Client is free under the Apache 2.0 license and maintained by the RabbitMQ team. The cost is code that MassTransit would have given us: we declare the exchange, publish with publisher confirms and handle reconnecting ourselves, and the consumer side will need its own acknowledgements, retries and dead-lettering. Keeping that code small is possible because LedgerPay has a single event and a single consumer.
